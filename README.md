# stanzawhere

Shared Cursor workspace for João’s stanzawhere tool. Andrew and João both work here in Cursor against this GitHub repo.

## Get started

```bash
git clone https://github.com/ai-stanza/stanzawhere.git
cd stanzawhere
```

Open the folder in Cursor (File → Open Folder). Cloud Agents and local chats will share this repo once GitHub is connected under Cursor Integrations.
